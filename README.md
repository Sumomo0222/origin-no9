# ORIGIN No.9 · 九号原产 — 虚构单源巧克力品牌购物网站

一个**完全虚构**的精品巧克力品牌电商演示站点：单一产地（single-origin）排块、交互式世界产地地图、风味雷达图、拖拽自组礼盒、购物车抽屉、贺卡与模拟结算。

**线上地址**：https://sumomo0222.github.io/origin-no9/

> ⚠️ 免责声明：品牌、庄园、人物、产地故事、认证、价格均为虚构演示内容，不代表任何真实品牌、奖项或组织。所有「支付」均不会真实发生。

## 功能

- **交互产地地图**：Natural Earth 世界地图（d3-geo 预投影为内联 SVG），点击六个虚构产区金色坐标，展开庄园故事、风味签、采收/发酵档案与代表产品。
- **风味雷达图**：商品卡悬停（桌面）/ 点击图片（手机）展示 酸度 · 苦度 · 果香 · 坚果香 四维档案。
- **商品详情**：可选可可含量、包装规格（单条/二重奏/四联）、礼盒升级组合，价格实时联动。
- **组装礼盒**：4/6/9/12 格盒型；口味块可**拖拽**放入格位（Pointer Events，兼容触屏；点击也可加入），实时数量与总价，满盒自动 95 折。
- **购物车抽屉**：数量增减、移除、手写贺卡（三款卡纸 + 120 字留言），localStorage 持久化。
- **模拟结算**：收礼信息 → 配送方式（冷链/标准/自取）→ 模拟支付 → 订单号成功页。

## 数据集中管理

所有业务数据集中在 **`assets/js/data.js`**（品牌信息、产地故事、商品与价格模型、礼盒盒型与口味、贺卡款式、运费规则）。接入真实商品时只需替换该文件，页面代码零改动。

商品与产地的图片路径也写在 data.js / `assets/js/ui.js`（ORIGIN_PHOTOS）中，替换 `assets/img/` 下同名文件即可换图。

## 图片版权

站点照片来自可合法复用的免费图库（Unsplash / Pexels License），已下载至 `assets/img/` 本地托管。装饰插画（可可荚、叶枝、邮戳、蜡封、邮票框）为手写内联 SVG 原创图形。

## 技术栈

纯静态、零框架：原生 ES Modules + 手写 CSS 设计系统（可可棕/奶油白/深绿/金，「产地明信片」视觉语言：邮票齿孔、邮戳、蜡封、巡游路线虚线）。

- 世界地图：构建期用 `tools/build-assets.mjs`（d3-geo + topojson + world-atlas，公有领域数据）生成 `assets/js/map-data.js`，运行时零地理计算。
- 字体：Marcellus（拉丁标题）+ Noto Serif SC / Noto Sans SC（思源宋黑，按 unicode-range 子集按需加载），本地托管于 `assets/fonts/`。

## 本地运行

```bash
python3 -m http.server 8090   # 或任意静态服务器
# 打开 http://127.0.0.1:8090/
```

修改地图/字体资产后：`npm i && node tools/build-assets.mjs`
